# 数据源与参数说明 - 增强版

## 默认市场数据

### A股 / 港股指数
数据源：`https://hq.sinajs.cn/list=...`
状态：✅ 稳定免费

#### 接口格式差异（重要！）

**A股接口（s_ 前缀）**：只有 6 个字段
```
格式：名称,当前价,涨跌,涨跌幅,成交量,成交额
示例：var hq_str_s_sh000001="上证指数,4112.1593,4.6449,0.11,6569127,127619474";
字段：[0]名称, [1]当前价, [2]涨跌, [3]涨跌幅, [4]成交量, [5]成交额
```
⚠️ **常见错误**：不要假设 A股接口有 30 个字段（那是完整行情接口）。s_ 前缀是简化接口，只有 6 个字段。

**港股接口（rt_ 前缀）**：约 20 个字段
```
格式：代码,名称,今开,昨收,当前价,最高,最低,涨跌,涨跌幅,...
关键字段：[2]今开, [3]昨收, [4]当前价, [5]最高, [6]最低, [7]涨跌, [8]涨跌幅
```

**商品接口（hf_ 前缀）**：约 15 个字段
```
格式：最新价,昨收,买价,卖价,最高,最低,时间,...
关键字段：[0]最新价, [1]昨收, [2]买价, [3]卖价
```

#### 固定抓取
- `s_sh000001`：上证指数（s_ 格式，6字段）
- `s_sz399001`：深证成指（s_ 格式，6字段）
- `s_sh000300`：沪深300（s_ 格式，6字段）
- `rt_hkHSI`：恒生指数（rt_ 格式）
- `rt_hkHSTECH`：恒生科技指数（rt_ 格式）

### 黄金 / 白银 / WTI原油
**主力数据源**：新浪财经 `hf_XAU`, `hf_XAG`, `hf_CL`
- ✅ 稳定免费
- ✅ 直接提供涨跌幅
- ⚠️ 需要正确解析昨收和最新价

**Fallback**：Yahoo Finance `GC=F`, `SI=F`, `CL=F`
- ⚠️ 可能遇到429限流
- 作为备用数据源

### 美股指数（标普500/纳斯达克100/道琼斯）
**主力数据源**：Yahoo Finance chart API `^GSPC`, `^NDX`, `^DJI`
- ⚠️ **可能遇到429限流**（IP临时封禁）
- 遇到429时，建议等待一段时间再试
- 使用多个服务器fallback：`query1`, `query2`, `query`

**替代方案**（待实现）：
- Alpha Vantage（需要API key）
- IEX Cloud（需要API key）
- Polygon.io（需要API key）

## 增强功能

### 重试机制
- 最多重试3次
- 指数退避延迟（2秒、4秒、8秒）
- 服务器切换时增加2秒延迟

### 数据源优先级
1. **A股/港股**：新浪财经（唯一数据源，稳定）
2. **商品**：新浪财经 → Yahoo Finance（fallback）
3. **美股**：Yahoo Finance（多服务器）→ 失败则返回友好提示

### 请求延迟
- Yahoo请求间延迟5秒（避免429）
- 重试时指数退避
- 每个服务器尝试间隔2秒

## 参数说明

### `--extra`
用于按别名获取额外资产，如：
```bash
market_brief --extra copper bitcoin brent
```

内置别名：
- `copper` / `铜` → `HG=F`
- `bitcoin` / `btc` / `比特币` → `BTC-USD`
- `eth` / `ethereum` / `以太坊` → `ETH-USD`
- `brent` / `布伦特` → `BZ=F`

### `--ticker`
指定Yahoo Finance代码：
```bash
market_brief --ticker AAPL TSLA 0700.HK 9992.HK 600519.SS
```

### `--include-user-defaults`
附加用户默认关注：copper, bitcoin, 0700.HK, 9992.HK

## 常见问题

### 美股数据获取失败（429错误）
**原因**：Yahoo Finance对请求频率有限制，短期内请求过多会被临时封禁（通常几分钟到几小时）

**解决方案**：
1. 等待一段时间后再试
2. 减少请求频率（已内置5秒延迟）
3. 使用`--extra`和`--ticker`时，避免一次性查询过多股票

### 涨跌幅显示N/A
**原因**：
1. 数据源未返回昨收价格
2. 只有单日数据，无法计算涨跌幅

**已修复**：新浪财经接口现在正确解析昨收和最新价，涨跌幅计算正常
